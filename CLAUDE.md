# CardioOncoPredict

## Миссия
Исследовательская программа: измерить микровольтную альтернацию зубца T (TWA) в ЭКГ и проверить, служит ли она ранним признаком кардиотоксичности антрациклинов. Нейросеть пока обучена только на задаче-заменителе (PTB-XL, пять общих диагнозов). Дальняя цель — мультимодальная оценка риска (ЭКГ + эхо/GLS/LVEF + анализы + терапия). Не медицинское изделие: никаких диагнозов, советов по лечению и слов «спасает жизни».

## Как рассуждать
- Первые принципы и мысленный эксперимент до кода; если не объясняется просто — значит, не понято (Эйнштейн, Фейнман).
- Точная модель с явными допущениями: что вход, что выход, что шум, сколько информации реально в сигнале (Ньютон, фон Нейман, Шеннон).
- Не объявлять результат верным, пока он не проверен; каждое утверждение — либо измерено (с тестом или рисунком), либо помечено «гипотеза» (Перельман).
- Искать способ опровергнуть свою модель: абляция, внешние данные, контрпримеры, отложенная выборка (Поппер).
- Интервалы неопределённости вместо одного числа: бутстрэп, несколько seed (Байес).
- Простота и минимум: убирать лишнее из кода и интерфейса; сначала самое простое рабочее решение (Джобс, Возняк, Маск).
- Всё воспроизводимо одной командой: данные → обучение → отчёт (Форд). Сначала описать готовый результат для врача, потом строить (Безос). Маленькие шаги и проверка каждого (Цукерберг).
- Силы — на главную метрику и главный риск; осторожность с клиническими утверждениями (Наполеон, Кутузов).
- Прочно, полезно, красиво (Витрувий). Определять термины до использования и знать границы знания (Кант, Декарт, Гёдель).
- Не уверен в факте, ссылке, метрике или определении — так и сказать и проверить по первоисточнику (PubMed, Crossref, документация). Ничего не выдумывать.

## Медицинский домен
- CTRCD определяют по LVEF, GLS и биомаркерам; пороги брать из ESC 2022 (Lyon et al., README ссылка 3) и сверять с текстом.
- Факторы риска: антрациклины (доза), трастузумаб, ингибиторы контрольных точек, лучевая терапия, возраст, пол, гипертония, диабет, ИБС, исходная ФВ, удлинение QT, тропонин, NT-proBNP.
- Крайние случаи: пропуски, артефакты, разные частоты и приборы, дети и пожилые, сочетания препаратов, дисбаланс классов, смещение по полу, возрасту и этносу.
- Риск меняется во время лечения: сравнивать ЭКГ пациента с его исходной (каждый сам себе контроль); для времени до события — survival-модели.
- Корреляция — не причинность; без причинного анализа причинных выводов нет.

## Данные и протоколы, которые нельзя нарушать
- PTB-XL: деление по пациентам, strat_fold 1–8 обучение, 9 валидация, 10 тест. Подбор чего угодно — только на валидации; тест — только для итоговой оценки.
- Конкурс PhysioNet 2008 по TWA: половина реальных записей «real-test» уже использована для v0.6; разработка — только на синтетических и «real-dev» (`scripts/validate_twadb.py --only ...`).
- Детектор R-пиков проверяется на MIT-BIH и SVDB (`scripts/validate_rpeaks.py`); обе базы уже видели при выборе метода.
- Для кардиотоксичности нужны данные пациентов на терапии — только через клинического партнёра, с одобрением этического комитета и деидентификацией. Других источников (MIMIC-IV-ECG, CODE-15%, Chapman–Shaoxing, Challenge 2021) — проверять условия доступа и лицензии до загрузки.

## Структура (реальная)
- `cardioonco/` — библиотека: `synth`, `preprocess` (фильтры, R-пики по Elgendi), `twa` (спектральный метод, MMA, три исхода), `model` (CardioOncoNet), `fhir`.
- `assets/js/dsp.js` — та же математика для сайта; совпадение с Python проверяется тестами.
- `train_ptbxl.py`, `predict.py`, `app.py`; `scripts/` — загрузка данных, проверки, рисунки; `models/ptbxl-1.0/` — опубликованные веса (5 seed) и карточка модели; `docs/results/` — таблицы результатов; `docs/figures/{en,ru}/` — рисунки; `tests/`.
- Предложенную структуру `src/…` не вводить: пути библиотеки архивированы в Zenodo по версиям, а пакет уже покрыт тестами.
